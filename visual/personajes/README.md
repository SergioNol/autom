# Personajes (serie Caso real)

Imágenes de referencia de los simios fijos de `visual/guia-estilo.md`, para que se vean iguales mes tras mes.

```
rafa.jpg   chela.jpg   tono.jpg   lupe.jpg
```

## Cómo se crean

1. La primera vez que aparece un personaje, el modelo lo genera solo con su descripción.
2. Cuando apruebes un post en el que salga bien, copia su fondo sin texto de
   `generacion/AAAA-MM/fondos/<carpeta>/imagen-N.jpg` aquí, con el nombre del personaje (`rafa.jpg`).
   Mejor una imagen de cuerpo entero, en pose neutra y con fondo liso.
3. A partir de entonces, el plan lo incluye en `referencias` de todas las diapositivas de ese personaje.

Para cambiar a un personaje, sustituye su imagen (y su descripción en la guía, si cambia).
